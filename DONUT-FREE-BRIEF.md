## Архитектура: режим `free` вместо тест-флага (ключевое требование)
Готовая сборка НЕ должна работать «на тест-флаге» (`e2e`, `TAURI_AUTOMATION`, `WAYFERN_TEST_TOKEN`, `DONUT_E2E_DISABLE_STARTUP_NETWORK`): с ним отключается часть функций (proactive-скачивание движка/xray/GeoIP — downloaded_browsers_registry.rs:1506/1661) и в бинарник попадает тестовая поверхность.

Делаем первоклассный режим:
1. **Новый cargo-фич `free = []`** (`src-tauri/Cargo.toml`, рядом с `e2e`). Прод-сборка: `pnpm tauri build --features free`. Фича `e2e` в прод-бинарник НЕ включается (остаётся для dev-тестов).
2. **Entitlements без логина и env**: в `cloud_auth.rs` capability-хелперы (`can_use_browser_automation` :1357, `can_use_cross_os_fingerprints` :1373, `automation_rate_limit` :1411, при необходимости `has_active_paid_subscription` :1312 — только для локального пути) получают ветку `#[cfg(feature = "free")] → локальный набор` (automation=true, crossOs=true, высокий rate limit; ВСЁ серверное — cloudBackup/cookieBot/remoteControl/remoteInteractive/team/scheduledAutomation — остаётся false). Никаких env-переменных для этого не нужно.
3. **Локальный MCP как прод-фича**: сегодня MCP-движок в проде доступен только через их облачный мост; локально — только e2e-эндпоинт `/v1/e2e/mcp` (api_server.rs:1064-1065, 1124-1134: «the app otherwise serves only over the remote bridge… never published»). Форк добавляет прод-роут `/v1/mcp` (реализация по образцу `e2e_mcp_message`, но: имя без e2e, та же цепочка middleware — auth → rate limit → terms, документация в OpenAPI). Флот получает локальный MCP без облака и без тест-флагов.
4. **Локальный Wayfern-токен без env**: трассировать, где `WAYFERN_TEST_TOKEN` уходит в запуск движка (кроме cloud_auth; искать в wayfern_manager/browser_runner/mcp_server) и вынести этот механизм под `free` как встроенный локальный токен (константа, без env). Проверка соответствия — их же тест `api_server_fingerprint_browser_tests.rs:168-316`: с токеном браузер отдаёт device, без — нет. Наш acceptance повторяет это рантайм-проверкой через REST/MCP.
5. **Автообновление приложения**: под `free` проверка апдейта отключается compile-time (по образцу app_auto_updater.rs:2037/2098, но без env) — их апдейтер не должен перезаписать наш exe. **Proactive-скачивание движка/xray/GeoIP при этом остаётся ВКЛЮЧЁННЫМ** (прод-поведение) — это и снимает проблему «с тест-флагом часть функций отключается».
6. **Аудит всех `cfg(feature = "e2e")`** (19 мест: api_server 1064/1124; app_auto_updater 2037/2098; cloud_auth 1312/1357/1373/1411/1740; dns_blocklist 325; downloaded_browsers_registry 1506/1661; feedback 253; geoip_downloader 233/240; lib 57/68/2623; team_roles 153) + всех env-читалок e2e. Для каждого места — строка в отчёте: поведение во free-сборке (вкл/выкл/нейтрально). Тестовые эндпоинты и WebDriver-плагин в прод-бинарник НЕ попадают.
7. **Фронт**: tauri-команда `free_build()` (или Next-env флаг) → `src/lib/entitlements.ts:98 getEntitlements` отдаёт локальный набор без логина; UI показывает кросс-ОС/automation без «Upgrade». Косметика (желательно): страница аккаунта показывает «Free local edition» вместо апсел-логина. К патчу — unit-тест.

## Оптимизация и закрытие дыр (hardening checklist)
- **Release-профиль**: `lto = true`, `codegen-units = 1`, `strip = true` (+ `opt-level` по умолчанию). Замерить и привести в отчёте: размер бинарника, время старта, память — до/после и против v0.29.6.
- **Сетевая поверхность**: все локальные серверы только на 127.0.0.1 (проверить REST/MCP и любые отладочные порты); токен-аутентификация на всём; `/v1/e2e/*` в прод-сборке → 404 (проверить); CORS `CorsLayer::permissive()` (api_server.rs:1089) — проанализировать и решить: оставить (обосновать) или ужесточить; решение зафиксировать в отчёте.
- **Приватность**: ноль обращений к api.donutbrowser.com кроме CDN движка/xray/GeoIP (netstat/логи, приложить); log_redaction включён; телеметрии нет (проверить).
- **Диск и логи**: ротация логов, автоочистка старше 7 дней; кэш движка не раздувается (старые версии подчищаются штатно — проверить).
- **Стабильность**: watchdog-рестарт (см. P0-4) с антиштормом; rate limit автосессий — высокий, но конечный (защита от зацикливания агента).
- Отчёт «дыры и недоработки»: список найденных при аудите мест, где поведение free-сборки отличается от оригинала/прода — каждое либо закрыто, либо явно задокументировано как принятое.
